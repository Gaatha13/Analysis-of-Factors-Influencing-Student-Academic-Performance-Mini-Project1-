# Analysis-of-Factors-Influencing-Student-Academic-Performance-Mini-Project1-

## Introduction

Student academic performance is influenced by various factors, including study time, absences, gender, parental education, previous failures, and school and family support. This mini project, titled **“Analysis of Factors Influencing Student Academic Performance,”** aims to explore the relationship between these factors and students' final grades. Microsoft Excel was used for data cleaning and preparation, while Microsoft Power BI was used to analyse the data and create an interactive dashboard. The project helps present academic performance patterns through visualisations and identify factors associated with better student performance.
